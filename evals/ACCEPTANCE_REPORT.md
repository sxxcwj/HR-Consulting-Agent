## 本轮缺陷修复

1. 范围外请求不再被五段结构校验错误扩展成 HR 分析。
2. API 请求期间按 Ctrl-C 可正常结束，不显示异常堆栈。
3. Agent 初始化的非预期异常转为安全、明确的错误提示。
4. README 补充进入项目目录、虚拟环境运行方式和常见错误排查。
5. 提示词限制原因、问题和建议数量，避免过度展开；禁止无依据给出企业期限、人数、比例、样本量或观察周期。
6. 未核验地区与专业意见时，不引用具体法规条款，不作泛化法律断言；普通管理问题不机械扩展劳动关系风险。

## 已知非阻断风险

- 结构校验不能从技术上保证模型内容永不幻觉，生产使用仍需保留人工判断，尤其是法律、薪酬和人员处置问题。
- DeepSeek 或网络可能间歇性不可用；CLI 会提供可理解的错误并允许重试。
- 当前进程会保留全部成功对话，过长会话可能增加延迟和上下文消耗。
- `.env 2.example` 是现有未跟踪旧样例，未包含真实密钥但变量名已过时；本轮未擅自删除。
- `vague_02` 仍有一次非致命表达一致性失败，后续提示词迭代应关注列表计数和内部一致性。
